# DC HQ Hub

Uma interface inicial completa para uma biblioteca digital de HQs.

## O que já existe
- Página inicial responsiva
- Catálogo com busca e filtros por era
- Cards de HQ
- Área de personagens
- Leitor em tela cheia (estrutura pronta para conectar PDF/CBZ ou uma fonte licenciada)
- Layout mobile
- Design dark inspirado em quadrinhos
- Estrutura simples para expansão

## Como abrir
Basta abrir `index.html` em um navegador moderno.

## Próxima etapa para transformar em uma plataforma real
Para armazenar e entregar arquivos, recomenda-se adicionar:
1. Backend/API
2. Banco de dados
3. Autenticação
4. Upload seguro
5. Armazenamento de arquivos
6. Leitor PDF/CBZ
7. Progresso de leitura e favoritos
8. Painel administrativo
9. CDN e regras de acesso

## Direitos autorais
A plataforma deve receber somente conteúdo que você possui, que esteja em domínio público ou cuja distribuição tenha sido autorizada/licenciada. O projeto não inclui scans de HQs da DC.
